# Beispiel-Entitäten ersetzen

| Bereich | Beispiel | Durch eigene Entität ersetzen |
|---|---|---|
| Anwesenheit | `person.daniel` | Eigene Person |
| Wetter | `weather.home` | Eigene Wetterintegration |
| SENEC Speicher | `sensor.senec_battery_state_of_charge` | Batteriestand in Prozent |
| SENEC Haus | `sensor.senec_house_power` | Hausverbrauch |
| SENEC PV | `sensor.senec_solar_generated_power` | PV-Leistung |
| Licht | `light.wohnzimmer`, `light.kueche`, `light.garten` | Shelly-/Tuya-Lichter |
| Kameras | `camera.eingang`, `camera.garten` | Eufy-Kameras |
| Wärmepumpe | `climate.waermepumpe` | Klima-/Wärmepumpenentität |
| Vorlauf | `sensor.waermepumpe_vorlauftemperatur` | Vorlauftemperatur |
| Pool | `sensor.pool_temperature`, `switch.pool_pump` | Pool-Sensor und Pumpe |
| FRITZ!Box | `sensor.fritz_box_*` | Eigene AVM-Entitäten |
| Kalender | `calendar.familie` | Eigener Kalender |
